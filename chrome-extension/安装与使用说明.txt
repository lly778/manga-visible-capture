Chrome 漫画可见区域批量截图扩展
================================

安装
----
1. 在 Chrome 地址栏输入 chrome://extensions/ 并打开。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个“chrome漫画可见区域批量截图”文件夹。
5. 建议点击拼图图标，把本扩展固定到工具栏。

使用
----
1. 打开你有权访问的漫画阅读页面，并自行完成登录或正常解锁。
2. 点击扩展图标，再点击“自动识别区域”。网页会用绿色边框短暂显示识别结果。
3. 若识别结果不准确，请点击“手动框选”，在页面上拖动框选。
4. 设置翻页等待时间和翻页方式。ZIP 文件名默认使用当前页面标题，也可自行修改。
5. 点击“开始批量截图”，保持该网页标签页在最前面。
6. 截图会持续进行，页面右下角会显示进度；完成所需页面后请点击“停止”。
7. 截图过程中不会逐张下载；停止后，会在 Chrome 默认下载目录中生成一个 ZIP。

自动识别说明
------------
- 扩展会在当前可见页面中查找较大的漫画图片、Canvas 或阅读器容器，并按面积、位置和形状选择最可能的区域。
- 它只读取网页元素的可见位置，不会读取或下载图片源地址。
- 有些网站把阅读器放在封闭组件或特殊画布中，自动识别可能包含工具栏或漏掉边缘；此时使用“手动框选”即可。

翻页提示
--------
- 日文漫画阅读器常用“点击左侧”进入下一页，因此默认选择此方式。
- 若方向不对，停止任务后改成“点击右侧”。
- 某些阅读器会拒绝程序生成的点击或方向键。这属于站点自身限制，本扩展不会绕过；此时只能手动翻页。
- 翻页等待时间由用户自行设置，默认为 0.5 秒，最短为 0.1 秒，可按 0.1 秒调整。
- 翻页等待时间和翻页方式会自动保存，手动框选后重新打开插件不会恢复默认值。
- 截图过程中重新打开插件只会显示当前任务状态，不会改变截图速度。
- 插件弹窗打开期间，截图和翻页等待会暂停；关闭弹窗后从剩余等待时间继续，不会因弹窗停留而突然加速。
- 如需在运行中修改等待时间或翻页方式，请修改后点击“应用设置到当前任务”，新设置从下一次翻页开始生效。
- 如果翻页后截取区域与上一张完全相同，扩展会视为翻页停止或已经到达末页，自动停止并打包，且不会保存重复图片。
- 首次建议在截取 2 张后手动停止，确认翻页方向和截图区域正确后再正式使用。

安全边界
--------
- 扩展只截取当前标签页实际可见画面，不读取或还原图片接口。
- 网址中的页码或地址发生变化、切换标签页、关闭页面或点击停止时，任务会结束并打包已经截取的图片。
- 截图会一直持续到用户手动或自动停止；请根据阅读器的翻页动画长度设置足够的等待时间。
- ZIP 文件名会预先替换 Windows 不允许使用的字符；若下载目录已有同名文件，Chrome 会自动追加序号以防覆盖。
- 截图会先暂存在浏览器内存中。高分辨率截图较多时会占用较多内存，建议分批处理。
- 不要用于绕过登录、付费、DRM、阅览期限或反爬限制。
- 请遵守作品版权、网站服务条款及所在地法律，不要传播或商业使用未经授权的截图。
