Chrome 漫画可见区域批量截图扩展
================================

安装
----
1. 在 Chrome 地址栏输入 chrome://extensions/ 并打开。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个“chrome漫画可见区域批量截图”文件夹。
5. 建议点击拼图图标，把本扩展固定到工具栏。

使用
----
1. 打开你有权访问的漫画阅读页面，并自行完成登录或正常解锁。
2. 点击扩展图标，再点击“自动识别区域”。网页会用绿色边框短暂显示识别结果，弹窗内也会显示尺寸。
3. 若识别结果不准确，请点击“手动框选”，在页面上拖动框选。
4. 设置翻页方式。每页自动检测画面，稳定后立即截图，无需单独测试或设置等待时间。ZIP 文件名默认使用当前页面标题，也可自行修改。
5. 点击“开始批量截图”，保持该网页标签页在最前面。
6. 截图会持续进行，页面右下角会显示进度；完成所需页面后请点击“停止”。
7. 停止后会打开保存页。点击“保存 ZIP”，选择保存位置；文件名默认使用漫画标题。
8. 取消或保存失败后可以重试。误关保存页，可点击插件中的“打开待保存的 ZIP”。请在关闭浏览器或重新加载扩展前完成保存，暂存文件不会永久保留。

自动识别说明
------------
- 扩展会在当前可见页面中查找较大的漫画图片、Canvas 或阅读器容器，并按面积、位置和形状选择最可能的区域。
- 自动识别后会检查画面左右两侧的黑色或深灰色留白。如果第一页只显示一页且位于屏幕左侧，会向右再预留一个同样宽的页面位置，以便后续双页完整截图；手动框选不受影响。
- 若阅读器容器上方或下方还有网页内容，且能识别出其中完整的漫画图片，会同时以漫画图片的顶边和底边为准。
- 一页由多块图片拼接时，会先合并图片块，再按完整双页的边界识别，避免把阅读器左右的白色外边包含进来；漫画图片自身的白色页边和首页补位仍保留。
- 双页画面左右外缘若有少量正常画面落在识别框外，会按相同规则补齐；不会额外加入固定宽度的黑边。
- 它只检查网页元素位置和当前可见画面，不会读取或下载图片源地址。
- 有些网站把阅读器放在封闭组件或特殊画布中，自动识别可能包含工具栏或漏掉边缘；此时使用“手动框选”即可。

翻页提示
--------
- 默认使用“发送向左键”翻页。若方向不对，停止任务后改成“发送向右键”；也可以手动选择点击画面左侧或右侧。
- 升级后，原来保存的左侧／右侧点击设置会一次性改成对应方向键；之后手动选择的方式仍会保存。所有网站统一使用所选方式，没有特定网站的翻页覆盖逻辑。
- 某些阅读器会拒绝程序生成的点击或方向键。这属于站点自身限制，本扩展不会绕过；此时只能手动翻页。
- 每次翻页都自动检测当前可见画面，无需单独测试翻页耗时或配置固定等待。可读取阅读器画布或已显示图片时每 40 毫秒检查画面、加载、位置、透明度和变换，也支持由多块图片拼接的页面。画面停止变化后再观察 120 毫秒即可确认并截图。只检查已渲染的画布和图片，不读取图片地址或阅读器数据接口。
- 若画布和图片均不可读或没有合适区域，会使用屏幕截图检测，受浏览器限制间隔至少 550 毫秒，再以一张未变化的采样确认。
- 可见的大块加载占位层（例如“LOADING…”）消失前不会截图，即使占位图本身已加载且画面静止；快速检测和慢检测都检查此状态。隐藏、被覆盖、区域外的预加载层和小型无关指示器不会阻塞已加载的漫画。
- 为双页预留的空白位置不会让开头的完整单页改用慢速检测；单页图片或拼接图片也会使用快速检测。若另一半出现可见的 HTML 按钮、标题或 SVG 图标（例如点赞区），改用慢检测并计入连续慢检测页数；普通页翻到这种画面也会切换，隐藏内容和边缘工具栏不会使空白补位改用慢检测。翻页中途被裁切的页面、缺失的图片块仍会阻止截图。使用屏幕截图检测时，直接复用刚保存的画面作为翻页前的比较基准，避免点击前再等待一次截图。
- 翻页中途出现不可读取像素的跨域图片时，会转用浏览器屏幕截图检测，并以刚保存的上一页截图继续比较；不会仅因检测方式切换就停止并漏掉末页。
- 慢检测期间会继续尝试快速检测，翻到可读取的普通漫画页后恢复快速确认稳定，再用一张屏幕截图核对翻页变化并直接保存该采样。
- 连续两页最终使用慢检测时，只保存第一页，第二页不保存，自动停止并导出；遇到快速检测页（包括从慢检测恢复的快速页）会清零。同一页的多次屏幕采样只算一页。
- 截图检测确认稳定后，标签页、截图区域和窗口尺寸仍一致时直接保存最后一张采样，避免再截图并排队等待。画面已截取、裁剪并存入任务后即可开始下一次翻页，PNG 编码在后台完成；导出 ZIP 前会等待所有编码完成，不增加每页固定等待。
- 页面跳转或停止时，先等待已发起的截图和暂存完成，再导出 ZIP；编码期间新加入的截图也会等待完成后一起打包，避免漏图或读取未完成的图片数据。
- 隐藏或被遮挡的预加载图片、加载失败的图片及不改变可见画面的动画不会阻塞；占据较大区域且位于最上层的未加载图片仍会阻止截图，容许小范围光标和重绘差异。
- 旧版本保存的固定等待时间和自动等待开关不再生效，始终逐页检测稳定后截图。
- 已成功翻页后，以最近四次翻页中最慢的稳定耗时的两倍作为无变化停止期限，最低 1.2 秒、最高 8 秒；没有翻页记录时保留 8 秒。快速阅读器的末页检查通常约 1.2～1.7 秒，慢速阅读器会留出更多时间。这只用于判断是否已到末尾，不增加每页截图的固定等待。持续可见动画或未加载完成导致 30 秒检测超时也会停止并导出已截图片。进度会显示具体等待原因，采样检测不能保证识别所有特殊阅读器的延迟或动画。
- 翻页方式会自动保存，手动框选后重新打开插件不会恢复默认值。
- 截图过程中重新打开插件只会显示当前任务状态，不会改变截图速度。
- 插件弹窗打开期间，截图和稳定检测会暂停；关闭弹窗后重新确认画面稳定，不会因弹窗停留而突然加速。
- 如需在运行中修改翻页方式，请修改后点击“应用翻页方式到当前任务”，新设置从下一次翻页开始生效。
- 如果翻页后漫画主体画面与上一张基本相同（允许少量动画或重绘差异），扩展会视为翻页停止或已经到达末页，自动停止并打包，且不会保存重复图片。
- 首次建议在截取 2 张后手动停止，确认翻页方向和截图区域正确后再正式使用。

安全边界
--------
- 扩展只截取当前标签页实际可见画面，不读取或还原图片接口。
- 网址中的页码或地址发生变化（包括整页跳转）、切换标签页、关闭页面或点击停止时，任务会结束并打包已经截取的图片。
- 截图会一直持续到用户手动或自动停止，翻页后始终自动确认画面稳定。
- ZIP 文件名会预先替换 Windows 不允许使用的字符；如选择已有文件，由系统保存对话框确认是否覆盖，不再自动追加序号。
- ZIP 通过浏览器的文件保存功能直接写入所选位置，不使用下载权限或下载重命名监听，从而消除与 IDM 的下载重命名冲突，无需禁用 IDM。
- 需要支持直接保存文件的桌面版 Chrome 或 Edge；不支持时会提示错误，不会自动改用可能被 IDM 接管的下载方式。
- 截图会先暂存在浏览器内存中。高分辨率截图较多时会占用较多内存，建议分批处理。
- 不要用于绕过登录、付费、DRM、阅览期限或反爬限制。
- 请遵守作品版权、网站服务条款及所在地法律，不要传播或商业使用未经授权的截图。
